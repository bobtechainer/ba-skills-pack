Template A: iBank2 — Đặc tả màn hình

Dùng cho: Web banking, iBanking, dự án có MH nhiều field, bảng dữ liệu, dropdown, validate phức tạp

⚠️ RULES BẮT BUỘC:
  1. Mỗi field PHẢI có 2 phần: Tác nhân + Logic xử lý
  2. Liệt kê TẤT CẢ API — thiếu → placeholder + [MANUAL]
  3. Bảng field PHẢI có UI chrome: Nav Bar, Breadcrumb, Progress Bar, Loading
  4. Popup PHẢI có 4 phần: Icon + Tiêu đề + Nội dung + Buttons
  5. Lưới dữ liệu PHẢI ghi phân trang
  6. Mockup → PHẢI chèn ngay dưới "a. Mockup Màn hình"

📝 Hướng dẫn viết cột Mô tả — BẮT BUỘC theo pattern:

1. Tác nhân
NSD: hành động gì (chọn, nhập, click)
Client: hiển thị gì
Server: trả về gì

2. Logic xử lý
+ Quy tắc nghiệp vụ: liệt kê rules
+ Mặc định: giá trị mặc định khi mở MH
+ Nguồn giá trị: API nào, bảng nào
+ Validate: rule + thông báo lỗi

3. Popup (nếu có) — BẮT BUỘC đủ 4 phần:
Icon: Lỗi / Thông báo / Xác nhận
Tiêu đề: «tiêu đề popup»
Nội dung: «nội dung tiếng Việt»
Button: Hủy bỏ → action, Xác nhận → action
