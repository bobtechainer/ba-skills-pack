3.4 Mô tả chi tiết màn hình — Bước «N»

«Tên field» «TextBox / Label / ComboBox» «M / O» «Editable / Read-only» «Mô tả chi tiết»
📝 Hướng dẫn viết Mô tả field:

Label: Giá trị từ API «endpoint»
TextBox: Placeholder + Min/Max + Format + Maxlength
ComboBox: API danh sách + Default + Filter + Khi đổi → reset field
Button: Click → action + Validate trước
