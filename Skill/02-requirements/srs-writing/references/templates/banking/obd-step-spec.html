📝 Hướng dẫn viết cột Mô tả:

Label / Read-Only: Giá trị lấy từ API «endpoint» field «field_name»

TextBox: Placeholder + Min/Max + Format + Maxlength

ComboBox: Gọi API «endpoint» lấy danh sách → Default → Filter logic → Khi thay đổi → reset field nào

Button: Click → action + Validate trước khi action
